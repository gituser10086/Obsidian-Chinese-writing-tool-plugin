This Obsidian plugin provides three functions:

1. Word count: Counts all characters including punctuation, excluding spaces and line breaks. The same as Jinjiang.

2. Formatting: Removes redundant spaces and ensures each paragraph is separated by a single blank line before and after, suitable for Jinjiang publishing. Accessible from the file's menu.

3. Chinese double quotes: The **Insert Chinese double quotes** command inserts `“”` and places the cursor between the quotation marks. If text is selected, the command wraps the selection in Chinese double quotes.

## Assign a hotkey

1. Open **Settings → Hotkeys** in Obsidian.
2. Search for **Insert Chinese double quotes**.
3. Select the plus button and press the key combination you want to use.
